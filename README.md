# MobileDev
Requirements and goals: The event tracking app I made is designed to help users create, view, edit, delete, and receive reminders for events
Screens and features: The app has a login, event grid, add or edit event, and sms permission screen.
Coding approach: I approached the coding process by breaking the app into smaller parts like login, database setup, event management, nd notification permissions.
Testing: I tested the app in the Android emulator by creating accounts, logging in, adding events, deleting events, and checking the notification behaviors.
Challenges: One challenge was making sure the Java and XML IDs were all connected correctly and how to get into the code view.
Successful component: I was most successful with the event database and the grid display because it showed how the user data could be stored, updated, deleted, and displayed.
